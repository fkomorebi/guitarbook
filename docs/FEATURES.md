## 调音器

- 范围：标准调弦 E2/A2/D3/G3/B3/E4，A4=440 Hz；默认自动识别所拨空弦，可点击琴弦切至手动模式，实时显示平滑后的检测频率、音分偏差和调音方向；刻度指针以动画移动，中央标出 ±5 音分准音区。持续处于 ±5 音分至少 600 毫秒后显示“已调准”，超过 ±7 音分解除确认；区间内尚未确认时显示“接近准音 · 请保持”。其他调弦与基准音调整待后续确定。
- 入口：首页调音器卡片。默认自动模式，未识别前保留六弦 E2 作为初始目标；点击开始调音才请求麦克风权限。自动模式单独拨响任意空弦，手动模式拨响所选空弦，调整弦钮；点击停止、离开页面或进入后台即停止采集。
- 平台：Android、iOS、macOS、Windows、Linux、Web 接入 record PCM16 音频流，均待构建与真机验证。Web 需要 HTTPS 或 localhost；Linux 需要 parecord、pactl、ffmpeg。系统或浏览器可能限制采样率或音频设备。
- 权限与数据：Android RECORD_AUDIO，Apple 麦克风用途说明及 macOS 音频输入 entitlement；其他平台使用系统/浏览器麦克风授权。音频只在内存分析，不保存、不上传。
- 异常：拒绝授权提示系统设置后重试；采集失败提示检查设备与权限后重试；丢音后保留读数最多 3 秒；超过 450 毫秒标明“上次读数 · 请重新拨弦”并解除调准确认，3 秒后清空；自动识别候选未稳定时沿用此保持规则；切弦、停止时立即重置。谐波、噪音和同时拨弦可能影响识别。
- 平滑反馈设计：4096 样本窗口、2048 样本步进；音分使用约 160 毫秒时间常数的指数平滑；调准确认同时检查原始偏差，避免平滑掩盖走音。已实现；拥塞时分析最新完整窗口，避免积压旧读数。
- 余音优化设计：RMS 门槛从 0.008 降至 0.003，保留 YIN 周期置信度过滤；采集降噪、自动增益和回声消除仍关闭。已实现，静态分析与独立 Dart 检查通过；实际余音与噪声环境效果待设备验证。
- 实现状态：已实现页面、PCM16 分帧及 YIN 周期检测，分析约 46–1100 Hz 的单音；依赖 record 7.1.2。Android 最低 API 24。
- 反馈验收：持续稳定前不显示已调准；确认后 ±5～7 音分边界抖动不反复切换，超过 ±7 解除；短暂丢音不闪烁，450 毫秒无可靠音高后标记为上次读数并解除确认，3 秒后清空；切弦及停止重置。小屏、大字号及明暗主题指针和状态均可读。
- 反馈验证（2026-10-27）：格式化、静态分析通过；独立 Dart 检查覆盖平滑、600 毫秒确认、迟滞、丢音中断确认、超时清除及重置并通过。已补充状态单元测试及页面准音区/大字号检查，但 Flutter 测试受本地端口限制未启动。各平台视觉与实际采集效果待设备验证。
- 验收：六根空弦及上下偏差的合成音测试；静音无读数；页面能进入、选弦及适配小屏；权限与生命周期测试；各平台实际采集与调音效果单独验证。

## 自动识别选弦（2026-10-27）

- 已确认范围：标准六弦按检测频率与目标的音分距离识别，不做八度折叠；默认自动，点击琴弦进入手动，打开“自动识别琴弦”可恢复。
- 识别规则：最近目标需在 ±180 音分以内，同一候选持续至少 180 毫秒才切换；无效音高中断候选，候选采样间隔超过 450 毫秒重新计时。候选未稳定时保留旧读数但立即解除调准确认；确认切弦时清空旧反馈；静音不自动轮换琴弦。
- 限制：仅适合接近标准调弦的单根空弦；严重走音、谐波和多弦可能误判，可手动选择。六个平台共用识别逻辑，不新增权限或数据保存。
- 验收：六弦及偏差识别、越界拒绝、短暂误判不切弦、丢音重置候选、切弦反馈重置、自动/手动切换。
- 实现与验证状态：已实现自动识别与手动切换。格式化、静态分析通过；独立 Dart 检查通过六弦及 ±150 音分、无效/越界频率、不折叠八度、候选防抖、丢音与长间隔重置。已补充识别单元测试和模式切换组件测试，Flutter 测试因环境禁止绑定本地端口而无法启动。各平台构建未重新验证，实际麦克风效果待验证。

- 余音优化验证（2026-10-27）：格式化与静态分析通过；独立 Dart 检查通过六弦弱音（振幅 0.006）、低于门槛的弱音拒绝、静音/直流/随机噪声拒绝、原有六弦及偏差检测、450 毫秒旧读数标记和解除确认、3 秒清除边界、恢复时清除旧平滑历史、候选中断保留读数及自动选弦回归。Flutter 测试仍因禁止绑定本地端口未能启动；各平台真实余音持续时间和噪声效果待验证，未新增设备验证结论。

## 节拍器

- 范围：30–240 BPM（默认 100），每小节 1–12 拍（默认 4），首拍重音和声音默认开启。提供速度滑块、±1 按钮、拍数选择、声音与重音开关及开始/停止。
- 操作：运行中修改速度、拍数、重音或声音开关时立即静音旧播放，准备新小节并从首拍开始。有声启动先显示“正在准备声音…”，准备期间可停止；首拍在音频准备好后播放。关闭声音直接进入独立可视模式。停止、返回或进入后台取消旧加载与播放，回前台不自动恢复。
- 音频设计：预生成包含拍音和拍间静音的一小节单声道 PCM，使用引擎无缝循环播放；Dart Timer 不触发声音。源采样率取最接近 48000 Hz 的 BPM 整数倍，使每拍恰有 sampleRate × 60 / BPM 个采样帧，小节长度没有整数帧取整误差；引擎按设备采样率重采样。此算法保证源数据的时长，实际输出还受重采样、设备时钟、缓冲与蓝牙影响，不承诺零延迟或专业音频级实测精度。
- 平台与依赖：Android、iOS、Windows、macOS、Linux 使用 flutter_soloud 4.1.7 原生引擎，初始化请求 48 kHz、512 帧缓冲；选用此版本以兼容当前 Flutter SDK 固定依赖。Web 直接使用 Web Audio AudioBufferSourceNode 的 loop 和 AudioContext 时钟，在点击事件中恢复音频上下文，无需 flutter_soloud Web 脚本或 COOP/COEP 响应头。Linux CMake 关闭不使用的 Xiph 解码库，仅需 PCM/WAV，不再依赖 GStreamer。其余平台构建仍待验证；平台工程存在不代表运行已验证。
- 权限与数据：无需麦克风权限，不保存、不上传数据；生成的音频仅驻留内存。系统音量、静音和输出设备影响播放，Web 需浏览器支持 Web Audio 并由用户点击开始。
- 显示：有声模式每约 16 毫秒读取引擎逻辑播放位置并更新当前拍，取消 60 毫秒颜色渐变；界面卡顿不再逐拍推迟或丢弃声音。纯视觉模式使用单调时钟计算当前拍并跳过错过的显示帧。逻辑播放位置不含全部物理输出延迟，因此声画同步仍需设备验证。
- 生命周期：参数切换立即暂停/停止旧声音；串行加载并用代次标记阻止过期任务启动。原生引擎生命周期在多个页面实例间共享并串行处理，退出时释放本页音源，最后一页释放其初始化的引擎；Web 退出时关闭本页 AudioContext。
- 异常：初始化、解锁、加载或读取播放进度失败时停止并提示重试；可关闭声音使用视觉模式，不要求初始化音频设备。
- 验收：211 个整数速度 × 1/4/12 拍的精确帧数；重音仅位于首拍，循环边界为静音；WAV 采样率与 PCM 编码；启动、加载期间停止/后台/退出、快速参数切换、声音开关、音频失败恢复；小屏、大字号及明暗主题可读。分别验证算法、组件、平台构建和设备播放。
- 实现状态（2026-10-27）：以上音频时钟改造已实现，依赖解析与静态分析通过；Linux Debug 和 Web Release 构建通过。完整 Flutter 测试 25 项全部通过（其中节拍器 12 项）。六个平台实际声音、长时间精度、设备权限/生命周期与输出延迟仍待实测。
- 相关回归修复：调音器刻度标签使用可换行的等宽区域，修复 320 像素窄屏、双倍字号时横向溢出；不改变调音检测行为。

本次验证（2026-10-27）：`flutter analyze --no-pub` 通过，`flutter test --no-pub` 25 项全部通过（含节拍器 12 项）；Linux Debug 与 Web Release 构建通过。测试连接绕过 localhost / 127.0.0.1 代理后成功。已检查 Linux 产物不再链接 Xiph 编解码库。以上结果不替代各平台实际音频、长期节拍误差或蓝牙延迟实测。

## 音阶指板

- 设计状态：本次新增，已实现；目标为标准调弦六弦吉他的离线音阶查阅。
- 教学说明（已实现）：页面先解释音阶、主音、级数、半音及升降号；每种音阶分别提供结构特点、听感描述与练习建议，随音阶选择更新。用当前主音生成入门练习，说明换调与换指型的区别，避免将听感或适用和弦视为固定规则。
- 范围：12 个主音；大调、自然/和声/旋律小调（上行）、大小调五声音阶、小调布鲁斯及七种自然调式。
- 操作：首页进入“音阶指板”，选择主音、音阶、CAGED / 一弦三音系统及把位；切换音名/级数，全指板显示音阶内音，当前把位实色高亮、根音描边，隐藏音阶外音；横向滚动查看空弦至 22 品的六线式指板，六弦在下、一弦在上，弦线贯穿，标明品号、品丝与品位圆点；超出 22 品的指型延伸展示并提示乐器限制。

## 和弦课程与练习

最后更新：2026-10-27。课程化改造已实现，最终验证见下文。

### 教学目标与课程范围

- 面向标准六弦调弦、左手按弦右手拨弦的初学者。默认“理解和弦”提供完整的学习单元，而不让初学者先面对全部参数。
- 12 课依次为：音名/弦品、音程、大三和弦、小三和弦、减/增三和弦、琶音与和弦奏法、重复音与声部、原位/转位、移调、大七/属七/小七、半减七/减七、综合应用。
- 每课包含学习目标、三个分段讲解、完整推导或对比例子、至少一段 TAB 及逐弦/读谱说明、三个画/说/弹任务、两道带解释的选择题。强调先定位和说出音名/角色，再逐音检查，最后一起弹。
- 具体内容包括：半音/全音与弦品；音程度数与性质；0/4/7 与 1/3/5；三度/五度的改变；同名音跨八度重复；最低音和转位；整体移动与改变性质的区别；三和弦上加入大/小/减七度。
- 参考用户提供的《MI音乐学院系列教材—吉他指板手册》引言及相关章节，新增阅读包括第 10–16 章（书内 33–52 页）。讲解与练习重新编排，TAB 使用计算或明确指法，保留章节阅读索引，不把教材全文/原页打包。

### 入口、导航与学习状态

- 首页“和弦练习”进入。顶部三个模式：“理解和弦”“自由探索”“按弦与转换”。默认显示第一课；切换模式后返回页首，页面存活期间保留课程及探索状态。
- 课程目录及上一课/下一课允许自由阅读，无强制解锁。跳课不计入完成。每课作答与任务勾选独立保存于本次页面内，切课不清空。
- 任务勾选为自评，纸上画图/说出/实际弹奏由用户完成，不自动判断。答题后显示正确答案和推理；可以改选。
- “记录本课自检”要求三个任务已勾选且两题均答对；进度按已记录的课数显示。修改为错误答案或取消任务时解除当前课完成记录；重练本课清除作答/任务/记录。未记录时即使做对也不自动增加完成数。
- 记录不等于演奏水平认证。退出页面清除状态，不做持久化、录音、音频播放或自动测评。

### 和弦与例谱数据

- 三和弦自由探索：12 根音 × 大/小/减/增 × 原位/第一/第二转位；音名按音程拼写，包含必要升降号及重升。实际 MIDI 音高、根音/三度/五度角色与弦品联动；同根音、同转位切换性质只移动发生变化的音，避免整组跳八度干扰比较。
- 自由探索使用高音三根弦的一个密集声部，每弦一音；提供同声部低—中—高—中—低的琶音。不是全指板所有指型，不指定手指编号。
- 七和弦课程：Cmaj7、C7、Cm7、Cm7♭5、Cdim7 五种公式与四音声部。五弦到二弦为根音—五度—七度—三度，六弦与一弦不弹。Cdim7 的第七音按 B♭♭ 拼写、实际为 A 的音高，避免混同半减七的 B♭。
- 按弦模式保留 Em/Am、Am/C、G/D、E/Am/Em/Am 四阶段与自评循环；六种开放和弦显示组成音、每弦音名/角色及文字指法，最后一步记录一轮。切阶段重置位置和轮数，可重练，不自动评定清晰度。
- 延伸和弦、七和弦全调/全转位、所有弦组、完整教材课程、左手琴镜像、持久化及音频示范未实现；是否及如何继续加入待确定。

### TAB、平台与权限

- 共用 `ChordTab`：一弦在上、六弦在下，品位数字而非手指编号；0 空弦，留空不弹，不用表示闷音的 x。竖排 TAB 谱号、13 像素弦距、衬线数字、分隔线和终止双线；静态例谱无位置光标，可点击练习谱以名称下短线标当前位置。
- 同列一起弹，跨列先后练习；分隔只是练习格，不标量化节奏、拍号、速度或时值，不播放。小屏横向拖动/滚动条，练习前进时自动显示当前列；明暗主题和字号自适应。
- Android、iOS、Windows、macOS、Linux、Web 共用纯 Flutter 离线界面；无新增权限或插件依赖。打包 Noto Serif 字体和 SIL OFL 1.1 许可证，应用许可证包含字体条目。
