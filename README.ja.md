# Guitarbook · 吉他宝典

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

Flutter 製のギター練習・即興演奏ツール集です。ドラムマシンでリズムを作り、Looper でフレーズを重ね、リアルタイムエフェクトで音を整えられます。

## ドラムマシン × Looper × エフェクト

- **ドラムマシン**：ロック、ファンク、ブルース、ポップ、フォーク、パンク、メタル、ディスコ、レゲエ、ヒップホップ、ジャズスウィング、ラテンの 12 種類の練習用プリセット。4/4 拍子・1 小節 16 ステップでキック、スネア、ハイハットを編集。30–240 BPM、スウィング、トラック別ミュート、音量調整に対応します。
- **Looper**：最初のループは 0.3–30 秒、最大 6 レイヤー。直前のレイヤーの取り消し、停止・再開、全消去が可能です。スマート録音では周囲のノイズを測定し、演奏開始で録音、約 2 秒の無音で終了して前後をトリミングします。キーボードやキーボード入力を送る USB フットスイッチを割り当てられます。
- **リアルタイムエフェクト**：ファズ、コンプレッサー、リバーブ、オーバードライブ、ディレイと、アメリカン・クリーン、ブリティッシュ・チャイム、ブリティッシュ・ロック、モダン・ハイゲインの 4 種類のオリジナルアンプ。最大 8 個を直列接続し、ドラッグによる並べ替え、個別調整、バイパスが可能です。Linux / Windows は対応する VST3 エフェクトも読み込めます。
- **同じ画面で即興演奏**：ホームのドラムマシンからワークスペースを開くと、3 つのツールを音量別に操作できます。Android / iOS / Linux / Windows の Looper はエフェクト処理後の音を録音します。モニタリングを開始し、実際のサンプルレートを 48 kHz にする必要があります。

標準チューニング用チューナー、メトロノーム、スケール指板、初心者向けコードレッスンもあります。README の翻訳はアプリ画面の多言語対応を意味しません。

## 使い方

1. ソースから起動し、ドラムマシンのワークスペースでプリセットを選んで伴奏を開始します。
2. エフェクトを使う場合はギターとヘッドホンを同じオーディオインターフェースに接続し、音量を下げてからモニタリングを開始します。ワークスペースのデバイス確認は無音です。独立したエフェクト画面では入室時にモニタリング開始を試みます。
3. エフェクト対応環境では 48 kHz でモニタリングしてから最初のレイヤーを録音します。macOS / Web はマイクを許可し、必要に応じてインターフェースのダイレクトモニターを使ってください。メインボタンを再度押すと録音を終了してループ再生し、もう一度押すと重ね録りできます。
4. 初期キー割り当ては **Space**：録音・重ね録り、**S**：停止・再開、**Z**：直前レイヤーを取り消し、**X**：全消去。設定から変更できます。ウィンドウにフォーカスが必要です。スマート録音は最初のレイヤーのみ対象です。

ハウリングや伴奏の再録音を避けるため、ヘッドホンを使用してください。ドラム単体にマイク権限は不要です。録音・チューナー・エフェクトには音声入力の許可が必要です。Android は API 24 以上、Apple 環境はマイク許可、Windows はシステムのマイクアクセス許可が必要です。Linux の直接入力録音には `parecord`、`pactl`、`ffmpeg` が必要です。Web は HTTPS または localhost、マイク許可、音声を有効にするユーザー操作が必要です。

モバイル版エフェクトはシステムの現在の音声経路とモノラル入力を使用します。アプリ内経路選択や外部 VST3 はありません。デスクトップ版は入出力・バッファを選択できますが、Windows に ASIO SDK は同梱しません。Bluetooth は低遅延の検証対象出力ではありません。

## 現在の制限

ドラムと Looper は独立したループです。自動テンポ同期、クオンタイズ、タイムストレッチはありません。音声はローカルのメモリ内のみで処理し、アップロードせず、ワークスペースを離れると消去します。書き出し、録音保存、エフェクトチェーンやデバイス設定の永続保存は未対応です。バックグラウンドに移ると停止し、復帰時に自動再開しません。MIDI やバックグラウンドのグローバルショートカットも未対応です。

アンプはオリジナルのアルゴリズムと簡易キャビネットフィルターで、IR 畳み込みやオーバーサンプリングはありません。外部プラグインは OS・CPU に対応するものを別途用意してください。表示されるドライバー遅延は物理的な往復遅延の実測値ではありません。実機の音質、USB インターフェース互換性、長時間の安定性は引き続き検証が必要です。

## ソースから実行

現在、公式インストーラーや公開 Web アプリはありません。Flutter と `pubspec.yaml` の Dart 条件（現在 `^3.12.0`）、対象環境の開発ツールを用意します。

```bash
flutter doctor
flutter pub get
flutter devices
flutter run -d <device-id>
```

デスクトップは `linux`、`windows`、`macos`、Web は `chrome` を指定できます。iOS は macOS と Xcode が必要です。ネイティブエフェクトは初回ビルドで JUCE 8.0.12 を取得し、CMake / C++ ツールを使います。Android は NDK と CMake 3.22.1 も必要です。JUCE の AGPLv3 / 商用ライセンスを含む依存関係のライセンスに従ってください。

詳細は [中国語のセットアップ・操作説明](README.md)、[デスクトップエフェクト](native/effects_host/README.md)、[モバイルエフェクト](native/mobile_effects/README.md)、[現在の機能設計](docs/FEATURES.md) を参照してください。

## PR 歓迎！

ドラムのリズム・音色、Looper の操作や同期、エフェクト DSP、プラットフォーム対応、アクセシビリティ、翻訳、ドキュメントへの貢献を歓迎します。大きな設計変更は、先に Issue で相談してください。

1. [AGENTS.md](AGENTS.md) と [機能設計](docs/FEATURES.md) を確認してください。
2. `flutter analyze` と `flutter test` を実行し、音声関連の変更には該当するネイティブのビルド・テスト結果も添えてください。
3. 動作が変わる場合は関連する各言語の README と機能設計を更新し、確認済みの環境と未検証の項目を明記してください。

デバイスの検証報告も歓迎します。OS、インターフェース、サンプルレート・バッファ、再現手順、結果を記載してください。第三者のプラグイン、利用制限のある音素材、個人の録音は含めないでください。
