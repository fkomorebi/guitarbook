# 吉他宝典（guitarbook）

吉他宝典是一个基于 Flutter 的跨平台吉他工具集合。项目将逐步加入不同用途的工具，并根据系统能力与权限适配不同平台。

## 当前进度

已实现 Looper 叠录、鼓机、工具首页、零基础和弦练习、音阶指板、节拍器页面和标准六弦吉他调音器：自动识别所拨空弦、支持手动选弦，实时显示平滑频率、音分偏差、动画指针及稳定调准反馈。麦克风采集与各平台实际运行尚待设备验证，尚未提供正式安装包或在线访问地址。

节拍器已改为音频引擎连续循环播放，按采样帧生成拍音；Linux Debug 与 Web 构建通过，实际音频延迟和各平台设备运行仍待验证。

功能的当前设计和实现状态见 [最新功能设计](docs/FEATURES.md)。开发时需遵循 [项目开发约定](AGENTS.md)，随功能变化同步维护文档。

## 运行与使用

当前通过源码运行。安装 Flutter SDK，满足 `pubspec.yaml` 中的 Dart SDK 约束（目前为 `^3.12.0`），并准备目标平台开发环境。以下命令在项目根目录执行：

```bash
flutter doctor
flutter pub get
flutter devices
```

根据 `flutter doctor` 补齐目标平台所需环境，从 `flutter devices` 获取设备 ID。

| 平台 | 运行条件 | 启动命令 |
| --- | --- | --- |
| Android | Android SDK，已连接的设备或已启动的模拟器 | `flutter run -d <Android设备ID>` |
| iOS | macOS、Xcode、模拟器或完成签名配置的真机 | `flutter run -d <iOS设备ID>` |
| Windows | Windows 主机及 Visual Studio 的 C++ 桌面开发环境 | `flutter run -d windows` |
| macOS | macOS 主机及 Xcode | `flutter run -d macos` |
| Linux | Linux 主机及 Flutter 所需桌面构建依赖 | `flutter run -d linux` |
| Web | Chrome 及 Flutter Web 开发环境 | `flutter run -d chrome` |

启动后点击“吉他调音器”，默认开启“自动识别琴弦”，点击“开始调音”并允许麦克风权限。拨响任意一根接近标准音高的空弦，稳定约 0.18 秒后自动选择对应琴弦；点击琴弦可切至手动模式，重新打开开关可恢复自动识别。在安静环境中一次拨响一根空弦，根据“偏低 / 偏高”缓慢调整弦钮；指针进入中央 ±5 音分准音区后，先显示“接近准音 · 请保持”，稳定约 0.6 秒后显示勾号和“已调准”；超过 ±7 音分会取消确认。丢音后保留读数最多 3 秒；超过约 0.45 秒显示“上次读数 · 请重新拨弦”，并取消调准确认，3 秒后清空。自动识别遇到短暂不确定音高时也保留上次读数，确认切弦后重置。已降低弱音检测门槛以接续余音，未开启采集降噪。标准调弦从六弦至一弦为 E2、A2、D3、G3、B3、E4，基准 A4 = 440 Hz。

点击“停止调音”、返回首页或应用进入后台会停止采集；回到前台需要手动重新开始。音频仅在本机内存中分析，不保存、不上传。拒绝权限后可在系统或浏览器设置中授权再重试；无读数时请检查选弦、环境噪声和麦克风。自动识别仅接受距离标准目标 ±180 音分内的音高，严重走音时请手动选弦；识别不进行八度折叠。谐波、同时拨弦和设备采样率差异可能影响结果，实际调音效果仍待设备验证。

Linux 可安装 `pulseaudio-utils` 和 `ffmpeg` 以提供上述命令。Web 使用安全来源；其他平台请检查系统麦克风隐私设置。当前仅支持标准调弦与固定基准音。

## 节拍器（2026-10-27）

从首页点击“节拍器”，选择 30–240 BPM、每小节 1–12 拍，点击“开始节拍”；默认 100 BPM、4 拍、首拍重音和声音开启。滑块或 ± 按钮调速；运行中改变速度、拍数、重音或声音开关，均停止旧播放并从首拍重新开始。有声模式先显示“正在准备声音…”，准备好后播放；准备期间也可停止。关闭声音可立即使用可视节拍；点击停止、离开页面或进入后台停止，回到前台需重新开始。不保存设置，不上传数据。

拍音和拍间静音预先合成为完整小节，交给音频引擎连续循环；声音不再由 Flutter 的逐拍 Timer 触发。原生五平台使用 flutter_soloud 4.1.7（兼容当前 Flutter SDK）；Web 直接使用 Web Audio 的 AudioBufferSourceNode 循环播放，无需额外插件脚本或跨源隔离响应头。Web 需要支持 Web Audio 的浏览器并由用户点击开始解锁音频。各平台系统音量、静音设置和输出设备影响声音，蓝牙仍可能增加输出延迟。

有声模式的拍点指示读取音频引擎的播放进度，取消原有 60 毫秒颜色渐变；纯视觉模式使用单调时钟。视觉刷新仍受界面帧率影响，播放进度不包含全部硬件/蓝牙输出延迟，因此不承诺声画完全同步或零延迟。首次启动和修改参数需要准备时间；长时间实际节拍误差仍需设备录音测量。

## 鼓机（2026-10-27）

首页点击“鼓机”，选择摇滚、放克或布鲁斯，点击“开始伴奏”即可循环即兴。固定 4/4 拍、一小节 16 步，支持 30–240 BPM 和摇摆调节（0 均分，33 近似三连音）。点击格子编辑底鼓、军鼓、踩镲；点击鼓件名称切换静音；宽屏同时显示 16 步，窄屏点击拍号分页查看全部步进，无需横向拖动。切换预设重置鼓点、静音及摇摆，保留速度。

运行中修改会准备新循环并从首拍重启；停止、返回或后台即停止，前台不自动恢复。当前设置退出页面即清除。鼓音为本地合成，鼓机本身无需麦克风权限；同页 Looper 录音需要授权。不保存、不上传音频。原生五平台复用 flutter_soloud，Web 使用 Web Audio，需点击开始解锁；系统音量、静音与蓝牙延迟会影响播放。拍点显示不保证与硬件输出完全同步。暂无多小节、自动加花、采样导入或保存功能。

## Looper 叠录与踏板控制（2026-10-27）

首页进入“鼓机”打开“即兴工作台”。桌面宽屏左侧为 Looper、右侧为鼓机；窄屏点击“鼓机 / Looper”页签切换，切换不会停止播放或清除录音。可选择先启动鼓机，再录吉他；二者独立循环，目前不自动量化到小节、锁定速度或拉伸录音。

1. 点击“录制第一层”或按空格，首次允许麦克风权限后开始演奏。
2. 再踩一次结束首层并循环播放；首层至少 0.3 秒、最长 30 秒，达到上限自动结束。
3. 播放中再踩一次开始叠录，再踩结束；叠录满一圈也会自动结束。新层加载好后按当前循环位置加入，原有层持续播放；最多 6 层。
4. 按 S 停止／恢复（恢复从循环开头开始），Z 撤销最近一层，X 清空全部。停止会丢弃未完成的录音，保留完成层；进入后台停止且不自动恢复，离开页面清空。

点击 Looper 标题旁的设置图标打开“踏板绑定与录音设置”，可为四个动作分别绑定键盘单键，点击绑定后按键，Esc 取消。重复绑定同一个键会转移原绑定，长按不重复触发；设置仅在本页面保存。支持模拟键盘输入的 USB 脚踏，要求应用窗口有焦点；系统或浏览器可能拦截部分按键。鼠标可绑定中键或两个侧键，仅在专用“鼠标踏板区”内触发，部分浏览器可能将侧键用于导航。MIDI、手柄和后台全局快捷键尚未接入。

录音设置可刷新并选择输入设备（麦克风或系统识别的声卡）；更换设备需先停止。可调 0–250 ms 输入延迟补偿，仅影响之后的叠录，按实际设备试听调整。请求 48 kHz 单声道 PCM 输入，实际格式与全双工能力取决于系统及设备；循环边界有短淡入淡出，各层固定衰减以预留混音余量。应用不提供实时软件监听，请使用耳机或声卡直通监听，以免把扬声器里的伴奏再次录入。

播放期间保持录音输入流，为下一次叠录做准备，页面持续显示“麦克风采集中”，非录音时丢弃输入；停止后关闭采集。音频只留在内存，不写文件、不上传，当前不支持导出或跨页面保存。权限拒绝、5 秒无输入、采集或播放失败会停止并提示重试，保留已完成录音。

原生五平台沿用 record + flutter_soloud，Web 使用 record + Web Audio。Android/iOS/macOS 需要已有麦克风授权，Windows 需系统允许麦克风访问，Linux 需 parecord、pactl、ffmpeg；Web 需要 HTTPS/localhost、麦克风授权及用户手势解锁。原生共享音频引擎，Web 共享 AudioContext；层间相位仍受采集块、驱动、设备时钟与输入/输出延迟影响，不承诺专业 Loop 踏板级同步。六平台实际录音、声卡、脚踏与鼠标兼容性待验证。

本轮验证：静态分析通过，完整 Flutter 测试 60 项通过（新增 Looper 12 项），Linux Debug 与 Web Release 构建通过。覆盖 PCM 跨块解码、相位映射、录音/叠录/撤销、30 秒和六层上限、加载取消、权限失败恢复、设备中断、后台停止、键鼠绑定逻辑及窄屏双倍字号深色布局。其他四平台构建与六平台真实录音、脚踏、鼠标、听感和长期同步待验证。
