# 吉他宝典（guitarbook）

吉他宝典是一个基于 Flutter 的跨平台吉他工具集合。项目将逐步加入不同用途的工具，并根据系统能力与权限适配不同平台。

## 当前进度

已实现 Looper 叠录、鼓机、工具首页、零基础和弦练习、音阶指板、节拍器页面和标准六弦吉他调音器：自动识别所拨空弦、支持手动选弦，实时显示平滑频率、音分偏差、动画指针及稳定调准反馈。麦克风采集与各平台实际运行尚待设备验证，尚未提供正式安装包或在线访问地址。

节拍器已改为音频引擎连续循环播放，按采样帧生成拍音；Linux Debug 与 Web 构建通过，实际音频延迟和各平台设备运行仍待验证。

功能的当前设计和实现状态见 [最新功能设计](docs/FEATURES.md)。开发时需遵循 [项目开发约定](AGENTS.md)，随功能变化同步维护文档。

## 界面与配色（2026-10-28）

全应用统一使用暖纸色背景、深青绿操作色，录音使用陶土色、调准使用绿色，并保留文字或图标提示。自动跟随系统明暗主题，统一卡片、按钮与输入样式。

首页按“练习准备 / 理解与练习 / 即兴创作”分组：先调音与练节奏，再进入和弦、音阶或实时效果器、鼓机与 Looper。点击整张工具卡片进入；宽屏双列，手机和大字号下单列，可纵向滚动。

本轮静态分析、69 项 Flutter 测试通过，已检查真实中文字体和图标的桌面明暗预览；Web Release 构建通过。各平台实际设备显示、操作与音频状态沿用下表，不能据此视为设备验证完成。

## 实时效果器宿主（Linux / Windows，2026-10-28）

已接入五类内置效果器及 VST3 实时效果器宿主代码，目标为 Linux 和 Windows；当前验证状态见下文。Android、iOS、macOS、Web 不支持本轮宿主能力，打开页面会显示平台限制。可在即兴工作台中与鼓机、Looper 同时使用；Linux / Windows 的 Looper 默认录下效果器处理后的声音（湿声）。

1. 吉他连接声卡的乐器输入，耳机接同一声卡；从首页进入“实时效果器”即自动尝试监听，空链输出干声。请先降低声卡耳机音量。启动失败时检查设备/权限后点击“开始监听”重试。
2. 需要更换设备时，先停止监听，点击“声卡与输入通道”，在独立设置窗口选择一个吉他输入通道、立体声输出、采样率及缓冲大小。Windows 使用本机可用的 WASAPI 等后端，本轮不包含 ASIO SDK；Linux 后端以设备设置实际列表为准。
3. 直接点击“Fuzz 法兹 / 压缩 / 混响 / 过载 / 延迟”添加内置效果，无需下载插件。也可输入适配当前系统和 CPU 架构的 `.vst3` 插件绝对路径，点击“加载插件”。Linux 示例：`/home/you/.vst3/MyEffect.vst3`；Windows 示例：`C:\Program Files\Common Files\VST3\MyEffect.vst3`。Linux 不能直接加载 Windows 插件。插件需自行安装，本项目不附带第三方音色；同一插件包有多个类型时加载第一个类型。
4. 页面顶部查看监听状态、输入/输出电平与削波提示；手动停止后可点击“开始监听”恢复。输出音量默认 50%，可在 0–100% 调节；关闭声卡直通监听可避免同时听到原始干声。
5. 内置和 VST3 可混合串联，合计最多 8 节；同一种内置效果可重复添加，各自参数独立。效果器板按真实单块的右进左出连接：右侧吉他输入 → 编号 1…N → 左侧输出；侧面插孔、跳线和箭头展示实际串联关系。点击前移/后移箭头排序、关闭图标移除；按金属脚踏开关切换旁通，旁通时状态灯熄灭，连接保留。监听时可自由添加、加载、移除、排序、旁通及转动参数旋钮，也可打开 VST3 参数窗口，无需反复停止/启动。结构切换可能短暂断音，旁通/移除会截断尾音。点击停止关闭音频设备；离页释放插件与引擎。最小化或进入隐藏/暂停状态停止监听，恢复后手动启动。


| 内置效果 | 可调参数（默认值） |
| --- | --- |
| Fuzz 法兹 | 驱动 1–30（12）、音色 200–8000 Hz（2500）、输出 0–100%（40%） |
| 压缩 | 阈值 −60–0 dB（−24）、比例 1–12:1（4:1）、启动 1–100 ms（10）、释放 20–1000 ms（300）、补偿 0–18 dB（3） |
| 混响 | 空间、阻尼、干湿比 0–1（0.5 / 0.5 / 0.25） |
| 过载 | 驱动 1–20（4）、音色 200–8000 Hz（4000）、输出 0–100%（60%） |
| 延迟 | 时间 20–1500 ms（350）、反馈 0–90%（35%）、干湿比 0–1（0.25） |

内置效果使用基础数字算法：Fuzz 硬削波、过载软饱和、立体声联动压缩、算法混响及反馈延迟；未包含箱体或特定硬件的建模。界面中的输出与反馈以 0–1 数值显示。每块效果器使用彩色金属外壳、螺丝、刻度旋钮、状态灯与金属脚踏开关，以更紧凑的尺寸摆放在纯色深灰效果器板上。旋钮上下拖动调参，点击旋钮打开精细滑块；键盘 Tab 聚焦后用上下键微调、Enter 打开精细调节。窄屏可触摸或鼠标左右拖动，并使用滚动条浏览整块板；默认从输入与第一块开始。VST3 使用独立单块外观，通过“参数窗口”调整实际插件参数。“声卡设置与延迟诊断”和“外部 VST3 插件”默认折叠，展开后可查看详细信息或输入插件路径。可从“压缩 → 过载 → 延迟 → 混响”开始尝试，也可以自由改变顺序。旁通会跳过处理、切断尾音，不做无缝切换。

Linux 默认请求 **48 kHz / 128 帧**；页面可在停止监听时切换 64 / 128 / 256 / 512 帧，实际生效值、每块时长、驱动输入/输出延迟、插件延迟及欠载次数分别显示。先用 128 帧；需要更低延迟可试 64 帧，出现爆音或断续则提高到 256 / 512 帧。驱动打开失败时会尝试较大缓冲并显示回退；不支持的手动值会报错。调整不会清除效果链或改选输入通道。

使用 PipeWire 默认设备时，宿主只在自己的进程内设置 `PIPEWIRE_QUANTUM`，使活动节点请求低缓冲；节点存在期间可能临时改变同一音频图中其他客户端的调度，关闭设备/离页后释放，不写系统配置或服务器 metadata。外部已设置的 `PIPEWIRE_QUANTUM` 优先。原生声卡设置仍可选择直接硬件设备；JACK 仅在构建时找到开发头文件才启用，还需运行中的 JACK 或 PipeWire JACK 兼容库。本机没有 JACK 开发头/兼容库，本轮实际验证的是 ALSA → PipeWire 路线。

本机延迟排查（2026-10-28）：Focusrite Scarlett Solo 4th Gen，PipeWire 在虚拟机中将最小 quantum 设为 1024。旧版默认 44.1 kHz / 512 帧，驱动报告输入输出合计约 69.7 ms；新版 48 kHz / 128 帧报告 16 ms，`pw-top` 确认活动图采用 128 帧，切到 256 帧后图也相应改变。以上是驱动报告和图调度验证，**不是物理回环实测往返延迟**；实际琴声听感、完整效果链的长期稳定性仍待验证。全湿延迟或混响本身也会推迟听到的声音，页面会提示；先旁通它们或降低干湿比，区分音色与监听延迟。

第一版不扫描插件目录、不保存效果链/参数/设备设置，不支持 VST2、LV2、虚拟乐器或跨系统插件桥接。插件崩溃会结束独立宿主，主界面可重新连接，效果链需重新加载。插件加载超时会结束宿主。设备与插件报告的延迟并非实测往返延迟，实际手感取决于声卡、驱动、缓冲和插件；蓝牙不作为低延迟验收输出。

桌面构建会同时编译 `guitarbook_effects_host` 并放到应用可执行文件旁，分发时保留整个构建目录。首次构建需联网下载 JUCE 8.0.12，要求 CMake 3.22+、C/C++17 工具链；Linux 还需 ALSA、X11、FreeType/Fontconfig 等开发依赖（Ubuntu 常见包：`libasound2-dev libx11-dev libxext-dev libxinerama-dev libxrandr-dev libxcursor-dev libfreetype-dev libfontconfig1-dev libgl1-mesa-dev`）。离线构建可先配置 `-DFETCHCONTENT_SOURCE_DIR_JUCE=/绝对路径/JUCE`，也可通过环境变量 `GUITARBOOK_EFFECTS_HOST` 指定已编译的引擎。JUCE 采用 AGPLv3 / 商业双许可，依赖许可见 [上游声明](https://github.com/juce-framework/JUCE/blob/8.0.12/LICENSE.md)。

若 Linux 构建报 `FETCHCONTENT_SOURCE_DIR_JUCE` 指向的目录不存在，说明构建缓存保留了失效的本地源码路径（例如已被清理的 `/tmp` 目录）。在项目根目录执行以下命令清除该覆盖，再重新运行；CMake 会将 JUCE 下载到构建目录的 `_deps/juce-src`，首次恢复需要联网。本地源码覆盖应使用长期保留的目录。

```bash

flutter run -d linux
```

## 运行与使用

当前通过源码运行。安装 Flutter SDK，满足 `pubspec.yaml` 中的 Dart SDK 约束（目前为 `^3.12.0`），并准备目标平台开发环境。以下命令在项目根目录执行：

```bash
flutter doctor
flutter pub get
flutter devices
```

根据 `flutter doctor` 补齐目标平台所需环境，从 `flutter devices` 获取设备 ID。

| 平台 | 运行条件 | 启动命令 |
| --- | --- | --- |
| Android | Android SDK，已连接的设备或已启动的模拟器 | `flutter run -d <Android设备ID>` |
| iOS | macOS、Xcode、模拟器或完成签名配置的真机 | `flutter run -d <iOS设备ID>` |
| Windows | Windows 主机及 Visual Studio 的 C++ 桌面开发环境 | `flutter run -d windows` |
| macOS | macOS 主机及 Xcode | `flutter run -d macos` |
| Linux | Linux 主机及 Flutter 所需桌面构建依赖 | `flutter run -d linux` |
| Web | Chrome 及 Flutter Web 开发环境 | `flutter run -d chrome` |

启动后点击“吉他调音器”，默认开启“自动识别琴弦”，点击“开始调音”并允许麦克风权限。拨响任意一根接近标准音高的空弦，稳定约 0.18 秒后自动选择对应琴弦；点击琴弦可切至手动模式，重新打开开关可恢复自动识别。在安静环境中一次拨响一根空弦，根据“偏低 / 偏高”缓慢调整弦钮；指针进入中央 ±5 音分准音区后，先显示“接近准音 · 请保持”，稳定约 0.6 秒后显示勾号和“已调准”；超过 ±7 音分会取消确认。丢音后保留读数最多 3 秒；超过约 0.45 秒显示“上次读数 · 请重新拨弦”，并取消调准确认，3 秒后清空。自动识别遇到短暂不确定音高时也保留上次读数，确认切弦后重置。已降低弱音检测门槛以接续余音，未开启采集降噪。标准调弦从六弦至一弦为 E2、A2、D3、G3、B3、E4，基准 A4 = 440 Hz。

点击“停止调音”、返回首页或应用进入后台会停止采集；回到前台需要手动重新开始。音频仅在本机内存中分析，不保存、不上传。拒绝权限后可在系统或浏览器设置中授权再重试；无读数时请检查选弦、环境噪声和麦克风。自动识别仅接受距离标准目标 ±180 音分内的音高，严重走音时请手动选弦；识别不进行八度折叠。谐波、同时拨弦和设备采样率差异可能影响结果，实际调音效果仍待设备验证。

Linux 可安装 `pulseaudio-utils` 和 `ffmpeg` 以提供上述命令。Web 使用安全来源；其他平台请检查系统麦克风隐私设置。当前仅支持标准调弦与固定基准音。

## 工程结构

- `lib/main.dart`：启动入口。
- `lib/app/`：应用配置和公共主题。
- `lib/features/tools/presentation/`：工具首页。
- `lib/features/tuner/`：调音页面、音频流处理及音高检测。
- `lib/features/effects/`：实时效果器界面与原生宿主控制协议。
- `native/effects_host/`：Linux / Windows VST3 实时音频宿主。
